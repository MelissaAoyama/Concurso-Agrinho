# Concurso-Agrinho
# Projeto Web: Agro Forte, Futuro Sustentável 🌾🚀

Website interativo desenvolvido exclusivamente para o **Concurso Agrinho 2026**, abordando o tema proposto: *"Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente"*.

## 🎯 Objetivo Pedagógico do Projeto
O site tem como propósito educar crianças, jovens e a comunidade escolar sobre a importância das novas tecnologias de precisão no campo e como elas viabilizam a produção em alta escala sem agredir os recursos naturais.

---

## ✨ Funcionalidades Principais (Gamificação e Dinamismo)

* **Quiz Interativo Automatizado (JavaScript):** Um jogo de perguntas e respostas para fixação dos conceitos de sustentabilidade do campo (plantio direto, economia de água e energia renovável).
* **Contador Progressivo de Impacto:** Um elemento dinâmico visual que prende a atenção do usuário simulando o benefício ambiental do monitoramento do solo por satélite.
* **Design Responsivo e Temático:** Layout adaptável para celulares, tablets e computadores, focado nas cores que remetem à tecnologia verde.
* **Acessibilidade e Semântica HTML5:** Uso correto de tags (`<main>`, `<section>`, `<header>`, `<footer>`) garantindo boa indexação e leitura.

---

## 🛠️ Tecnologias Utilizadas

1.  **HTML5:** Estruturação semântica do conteúdo.
2.  **CSS3:** Estilização moderna utilizando variáveis CSS, Grid Layout, Flexbox e efeitos de transição visual suave.
3.  **JavaScript (Vanilla ES6):** Lógica estruturada para gerenciamento de estados do Quiz (perguntas/respostas) e manipulação do DOM para o contador dinâmico.
